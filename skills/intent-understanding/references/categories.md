# Intent Recognition Categories

This reference lists the supported intents for mapping natural language to Capability Twin workflows.

## 1. Analysis Types
- `full_analysis`: Complete 6+3+4+N analysis.
- `supply_side_analysis`: Steps 1-6 (What Odoo has).
- `demand_side_analysis`: Steps 7-9 (What business needs).
- `gap_analysis`: Phase 3.5 (Bi-directional alignment).
- `capability_extraction`: Steps 10-13 (Refining results).
- `customization`: N Steps (Code generation).

## 2. Focus Areas
- `ecosystem`: Dependencies and integration.
- `technical`: Code, models, workflows.
- `function`: Business capabilities.
- `domain`: Tactical domain logic.
- `process`: End-to-end value chains.

## 3. Detail Levels
- `basic`: High-level summary.
- `comprehensive`: Standard detailed analysis.
- `deep`: Exhaustive source-code level analysis.
