# Context Memory Manager Skill

This skill provides context memory management capabilities for storing and retrieving context information in the Capability Twin framework.

## Features

1. **Short-term Memory**: Manages recent interactions and contextual history
2. **Long-term Memory**: Stores user preferences and accumulated knowledge
3. **Session Context**: Maintains session-specific context information
4. **User Preferences**: Manages user-specific preferences and settings

## Usage

This skill can be used to:
- Store context information for later retrieval
- Retrieve context based on type and user ID
- Update user preferences
- Maintain conversational context across sessions

## Integration

This skill integrates with the enhanced intent understanding skill and the Capability Twin framework to provide persistent context management.
